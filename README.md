Vehicle Counting README

Needed: 
    classifier_model.pt (classifier model), 
    yolo11n.pt (yolo model),
    live_view2.py (for model testing on live function),
    infer_two_stage.py (for model testing on uploaded videos)
    UI codes (using .net)

Use Visual Studio Code or VScode for the following files, use Visual Studio for the UI and SQL Server Management Studio 22 for database.

The team's current devices cannot merge the models and UI.
To connect the two, the models and the UI, we suggest to use FastAPI or Docker.
